from collections import deque

def shortest_path(graph, start, goal):
    pending = deque([start])
    parent = {start: None}
    while pending:
        node = pending.popleft()
        if node == goal:
            path = []
            while node is not None:
                path.append(node)
                node = parent[node]
            return path[::-1]
        for neighbor in graph.get(node, []):
            if neighbor not in parent:
                parent[neighbor] = node
                pending.append(neighbor)
    return None

This breadth first search returns a shortest path in an unweighted graph. Recording a parent when a vertex is first discovered prevents repeated visits and makes it possible to reconstruct the route. A weighted graph requires a different strategy, because the fewest edges do not necessarily give the lowest total cost. Dijkstra's algorithm handles nonnegative edge weights by processing the smallest known distance first.

A fair die has six equally likely outcomes. The expected value of a single roll is 3.5, obtained by summing the six outcomes and dividing by six. Two independent rolls have expected sum seven. Their sums are not equally likely: there is only one way to obtain two, while six ordered pairs produce seven. The variance of the sum equals the sum of the individual variances because the covariance is zero.
